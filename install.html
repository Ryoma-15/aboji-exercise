A home-screen shortcut · No app-store download

Add the Aboji Exercise app icon.

Open your member practice space from an icon on your device. This is a secure website shortcut—not a separate native app. Keep the approval email and its personal access link private.

iPhone · iPad

Safari

  1. Open this page in Safari (not an in-app browser).
  2. Tap the Share button (square with an up arrow).
  3. Choose Add to Home Screen.
  4. Turn on Open as Web App if shown, then tap Add.
Android

Chrome

  1. Open the member page in Chrome.
  2. Tap the three-dot menu.
  3. Choose Install app or Add to Home screen.
  4. Confirm. The Aboji Exercise icon will appear with your other apps.
Windows · Mac · Chromebook

Chrome or Edge

  1. Open the member page in Chrome or Edge.
  2. In Chrome, open the three-dot menu and choose Cast, save, and share → Install page as app (or use the install icon in the address bar).
  3. In Edge, open Apps → Install this site as an app.
  4. If install is not offered, bookmark the member page for quick access.
If you do not see the option

Try the full browser

Some browsers opened inside email or messaging apps hide home-screen installation. Open the link in Safari, Chrome, or Edge directly. The member sign-in may need to be completed in that browser once.

Return to member practice →

The home-screen icon opens the member website; it does not bypass member access. If your browser clears its data or your sign-in expires, use your personal approval link again or contact the team.

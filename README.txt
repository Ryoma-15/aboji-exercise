# アボジ体操 ホーム画面追加テスト（図入り版）

アップロードするファイル
- home-screen-test.html
- manifest.webmanifest
- sw.js
- app-icon-180.png
- app-icon-192.png
- app-icon-512.png
- guide-iphone.png
- guide-android.png

使い方
1. サイトの公開領域に、上のファイルをまとめてアップロードします。
2. `https://あなたのサイト/home-screen-test.html` を開きます。
3. 「ホーム画面に追加する」を押します。
4. iPhone / iPad では、図入りの大きな案内が表示されます。
5. Android / PC では、対応ブラウザなら追加ダイアログが出ます。出ない場合は図入りの案内を見て手動で追加します。
6. 追加後、ホーム画面の「アボジ体操」アイコンから開き、「テスト成功」と表示されればOKです。

補足
- iPhone / iPad では、Webページ側から自動で「ホーム画面に追加」を実行することはできません。
- Android は Chrome など対応ブラウザなら、ボタンからそのまま追加ダイアログを出せることがあります。
